# ProjectLib для Android

Нативный клиент ProjectLib (Kotlin + Jetpack Compose). Работает с тем же сервером, что и web-версия (`~/ProjectLib`). Внешний вид собран на Android-ките `universal-design-system`: Material 3, акцент `#0E8577`, светлая и тёмная темы. Спецификация лежит в `design-system/`.

## Что есть

| Как в web | На Android |
|---|---|
| Проекты: поиск, фильтр по статусу, карточки с прогрессом и запуском | ✅ |
| Проект: описание, статус, теги, ссылки, идеи списком или доской, меню ⋯ | ✅ |
| Идеи всех проектов: поиск, фильтры, сортировка, общая доска | ✅ |
| Канбан: перетаскивание по долгому нажатию, порядок внутри колонки | ✅ (`dragAndDropSource`); для TalkBack есть действия «Переместить в …» |
| Сроки, приоритет, вложения-картинки (загрузка на сервер) | ✅ (выбор фото через Photo Picker) |
| Запуск web-версии внутри приложения | ✅ WebView. В отличие от iframe, его не блокирует `X-Frame-Options` |
| Диплинк, магазин, загрузка, QR-код для другого устройства | ✅ Если приложение не установлено, предлагаем ссылку на установку |
| Локальные команды через агента на Mac | ⛔ Телефон не достаёт до агента на `127.0.0.1` у Mac, поэтому команда только хранится в проекте |
| Офлайн-синхронизация (`/api/sync`, очередь, SSE `/api/events`) | ✅ Тот же протокол: `data/SyncProtocol.kt` повторяет `src/lib/sync-protocol.ts` |
| Тема, экспорт и импорт JSON, демо-данные, удаление всего | ✅ |
| Liquid Glass (как iOS 27 в universal-design-system) | ✅ Glass mode Android-кита (Haze 2.1): без сплошных панелей — стеклянные кнопки сверху над затуханием контента, плавающая капсула вкладок с «линзой» (сворачивается при прокрутке), стеклянная FAB, меню, тосты; листы и диалоги — системное размытие Android 12+ за окном. Карточки, списки и поля сплошные. Кнопки, чипы и переключатели внутри контента тоже стеклянные — это отступление от дизайн-системы по желанию владельца; оно отключается в Настройках («Стеклянные кнопки в контенте») и рисуется без размытия фона (`dsGlassLook`), чтобы стекло не размывало само себя. Выключается в Настройках и сам — на слабых устройствах, при экономии заряда и выключенном системном размытии |
| Пользователи, роли, общий доступ | ✅ Режим только для чтения, «Мои / Со мной поделились», «Поделиться…», авторство идей, профиль, «Люди» (админ), приглашения |
| Вход по passkey | ✅ Через браузер: «Войти с passkey» открывает `https://project.lib/#/app-login` в Custom Tab, после passkey страница возвращает одноразовый код по ссылке `projectlib://pair`, и приложение получает свой сеанс (cookie `pl_session`) |

## Сборка

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Если к Mac подключено несколько устройств, ставь на нужное явно: `adb -s <serial> install -r …`. `./gradlew installDebug` ставит на все подключённые устройства сразу.

## Вход

1. **Войти с passkey** — основной способ. Сам Android не может вызвать passkey для приватного домена `project.lib`: связь приложения и домена проверяют серверы Google, а они до `.lib` не достают. Поэтому вход идёт через браузер телефона, где passkey работает.
2. **Ввести код** — на сайте: Профиль → «Подключить телефон», там же QR-код (камера телефона откроет приложение с уже заполненным кодом). Код живёт 10 минут и подходит один раз.
3. **Токен сервера** — запасной вход администратора (`PROJECTLIB_TOKEN`).

Если по ссылке `projectlib://pair` входит другой пользователь, копия данных прежнего удаляется с телефона. Ссылку, которую приложение не запрашивало само (QR-код, ссылка от кого-то), оно сначала показывает и ждёт подтверждения.

## Подключение к серверу

- **https://project.lib** (LAN, см. `DEPLOY-LAN.md` в web-репозитории): установи CA-сертификат `http://project.lib/ca.crt` в настройках Android (Безопасность → Шифрование и учётные данные → Установить сертификат → CA). Приложение доверяет пользовательским CA (`res/xml/network_security_config.xml`).
- **Эмулятор и сервер на этом Mac**: `http://10.0.2.2:3001`.
- Токен выводится при `npm run start:lan` и лежит в `data/lan.env`.
